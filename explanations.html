CSS File

The CSS file for the chess-themed website provides a cohesive and visually appealing design, covering various elements like the body, header, footer, navigation, main content, forms, tables, and interactive features like ChessBot and the quiz.

  • Body Styling: Dark background (#141414) with white text for high contrast and readability. Arial font for a clean look.
  • Header and Footer: Dark blue background (#000F46) with centered text for contrast and accessibility. The footer has extra padding and spans the full width.
  • Navigation: Horizontal layout with bold, white links that turn light grey on hover for a user-friendly experience.
  • Main Content: Padding for readability; white headings (h1, h2) for strong contrast.
  • Forms and Tables: Centered tables with solid borders and padded cells for readability.
  • ChessBot and Quiz: Flex container for ChessBot; changing border colours in quizzes to indicate correct or incorrect answers.

calculate.js

The calculate.js file handles the calculation of material advantage in a chess game with these key tasks:

  • Value Assignment: Assign values to chess pieces (pawns, knights, bishops, rooks, queens).
  • Input Retrieval: Gets the number of captured pieces from form inputs and calculates total values.
  • Material Advantage Calculation: Subtracts the opponent's total value from the player's total value.
  • Result Display: Shows the material advantage on the webpage for user interaction.

chatbot.js

The chatbot.js file manages ChessBot functionalities:

  • Random Persona Selection: Randomly selects a bot persona with unique names and images.
  • Greeting Display: Shows a greeting message with the selected bot persona's name and image.
  • User Input Processing: Processes user input, checks for keywords, and generates responses.
  • Keyword Response: Generates responses based on keywords in user input.
  • Typing Effect: Produces a typing effect for bot responses.
  • Response Display: Displays bot responses in the chatbox.
  • Handle User Input: Manages user input, adds it to the chatbox, processes it, and clears the input field.

quiz.js

The quiz.js file handles quiz functionality:

  • Form Submission Handling: Sets up an event listener to prevent default form submission behaviour using <form> and <input type="submit">.
  • Score Calculation: Compares user answers with correct answers and updates the score, indicating correctness with CSS classes.
  • Score Display: Shows the user's total score in an alert message for immediate feedback.

HTML Files

About Chess Page

The "About Chess" page is structured with a <header>, <main>, and <footer>. Styled with a dark background and white text. The <header> includes a navigation menu <nav> with links <a>. The <main> section has <article> elements containing <h2> headers and <p> paragraphs. JavaScript may add interactivity with ChessBot.

The Pieces Page

The "Pieces" page includes a <header> with navigation links, a <main> section with detailed chess piece descriptions, and a <footer>. CSS ensures a clean layout. JavaScript's ChessBot provides additional information. Descriptions use <b> for key points and <img> for visuals within <div class="image-container">.

Chess Terms Page

The "Chess Terms" page explains various chess terms using <section> and <article> elements. CSS enhances visuals and navigation. JavaScript adds interactivity for definitions on hover or click. Terms are highlighted with <b> and examples in <aside> elements.

ChessBot Page

The "ChessBot" page features a chat interface styled with CSS. JavaScript manages chat functions, including user input with <input type="text">, generating responses, and displaying messages with a typing effect. Messages use <p> for text and <div class="chat-box"> for layout.

Quiz Page

The "Quiz" page presents multiple-choice questions using <form>, <ul>, and <li> elements. Questions use <input type="radio">. CSS styles the quiz and provides feedback via class changes. JavaScript handles submission, score calculation, and display. Questions use <b>, and feedback is styled with CSS classes on <li> elements.

Piece Calculator Page

The "Piece Calculator" page helps users calculate material advantage in a chess game. The structure includes a <header> with navigation links <nav><ul><li><a>, a <main> with a <table> displaying piece values, and a <form> for input. CSS styles the form and table. JavaScript performs calculations, displaying results in <p> or <div> elements.
